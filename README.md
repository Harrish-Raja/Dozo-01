# Dozo · Dose done.

Interactive prototype of **Dozo**, the smart pillbox for grandparents, built for our Shark Tank pitch. All data is mock data.

**Pages:**
- `index.html` – product site: home, live demo (pillbox + family phone, voice in English, Tamil and Hindi), family app, care-home dashboard, pricing.
- `business.html` – investor view: go-to-market rollout and channels, unit economics calculator, growth simulator, shark deal room, company dashboard.

## Deploy on GitHub Pages
1. Upload `index.html`, `business.html`, `404.html` and `.nojekyll` to the root of this repo.
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, folder `/ (root)` → Save.
3. Open `https://harrish-raja.github.io/Dozo/` (product) or `https://harrish-raja.github.io/Dozo/business.html` (investors) after a minute.
